# 🍒 DIMPLES NYC-iCEE Website

Official website for **DIMPLES NYC-iCEE** — NYC's coolest frozen treat.

## 📁 Project Structure

```
dimples-nyc-icee/
├── index.html          ← Main website file (all pages)
├── README.md           ← This file
└── images/
    ├── logo.png            ← DIMPLES NYC-iCEE logo (black background)
    ├── brick-bg.png        ← Brick wall background texture
    └── first-event-flyer.png  ← May 24 event flyer
```

## 🌐 Pages Included

- **Home** — Hero, flavor lineup, brand vibe section
- **Events** — Upcoming event card (May 24 flyer), event type cards
- **Contact** — Phone, email, Instagram, booking form button

## 🚀 How to Deploy on GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Under **Source**, select `main` branch → `/ (root)`
4. Click **Save**
5. Your site will be live at: `https://YOUR-USERNAME.github.io/dimples-nyc-icee/`

## 🖼️ Updating Images

Replace any image in the `/images/` folder with the same filename to update it sitewide.

## 📅 Updating Events

To add or change an upcoming event, open `index.html` and find the section labeled:
```html
<!-- UPCOMING EVENT CARD -->
```
Update the flyer image, date, time, and location details there.
